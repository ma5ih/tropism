# Tropism — تروپیسم

صفحه اصلی تروپیسم، یک تجربه فارسی و کاملاً راست‌به‌چپ برای آشنایی با خدمات روان‌درمانی و شروع مسیر انتخاب درمانگر.

## اجرا

نیازمندی‌ها: Node.js 20.9 یا جدیدتر و npm.

```bash
npm install
npm run dev
```

سپس http://localhost:3000 را باز کنید.

## فرمان‌ها

- `npm run dev` — اجرای محیط توسعه
- `npm run build` — ساخت نسخه production
- `npm run start` — اجرای نسخه build شده
- `npm run typecheck` — بررسی TypeScript

## تصمیم‌های طراحی

- Next.js App Router و React
- زبان فارسی با `lang="fa"` و جهت سراسری `dir="rtl"`
- فونت وزیرمتن از بسته محلی `@fontsource/vazirmatn`
- رنگ‌های برند: `#6a804a`، `#9b76b4`، `#dbdbdb`
- سیستم مشترک فاصله‌ها، گوشه‌ها، دکمه‌ها، رنگ‌ها و انیمیشن‌ها
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- افکت Hover Overlay محدود به بخشی از تصویر کارت، نه کل کارت
- فرم درخواست جلسه فعلاً نمونه رابط کاربری است و اطلاعات به سرور ارسال نمی‌شود

## موارد لازم پیش از انتشار عمومی

1. جایگزینی لینک اینستاگرام با پیوند تأییدشده حساب رسمی Tropism.
2. اتصال فرم رزرو به بک‌اند امن و افزودن اعتبارسنجی سمت سرور و سیاست حفظ حریم خصوصی.
3. انتقال تصاویر بیرونی به دارایی‌های محلی دارای مجوز مناسب برای پایداری بیشتر.
4. افزودن محتوای واقعی مقالات و اطلاعات تماس مجموعه.

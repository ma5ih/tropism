# تروپیسم — فضایی برای رشد

صفحهٔ اصلی فارسی و راست‌چین برای برند تروپیسم، پیاده‌سازی‌شده با **Next.js 15، React 19، TypeScript و Framer Motion**.

## امکانات رابط کاربری

- طراحی واکنش‌گرا با هویت بصری سبز زیتونی، یاسی و پس‌زمینه‌های گرم
- هدر چسبان، منوی موبایل، هیروی تصویری و انیمیشن‌های ورود نرم
- معرفی پنج مسیر همراهی و باز شدن فرم انتخاب نوع جلسه
- راهنمای سه‌مرحله‌ای شروع، کارت‌های مجله و بخش اینستاگرام
- معرفی برند و فوتر چندستونه
- پشتیبانی از `prefers-reduced-motion`، حالت‌های فوکوس و چیدمان RTL
- لوگوی برداری در `public/logo.svg` و نشان مرورگر در `public/icon.svg`

## اجرای محلی

به Node.js نسخهٔ 20.9 یا جدیدتر نیاز است.

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

برای بررسی نسخهٔ نهایی:

```bash
npm run build
npm run start
```

## اتصال رزرو واقعی پیش از انتشار

فرم رزرو فعلی فقط یک نمونهٔ رابط کاربری است؛ فرم چیزی ارسال یا ذخیره نمی‌کند. برای رزرو واقعی، یک سرویس امن باید به آن متصل شود تا زمان‌های آزاد را بررسی کند، درخواست را ذخیره کند و پیام تأیید بفرستد. همچنین پیش از انتشار، نشانی نمونهٔ `hello@tropism.example`، حساب `@tropism.ir` و سیاست محرمانگی باید با اطلاعات واقعی مجموعه جایگزین یا تأیید شوند.

تصاویر تحریریه و دکور در این نسخه از URLهای Unsplash بارگذاری می‌شوند؛ در نسخهٔ نهایی می‌توان آن‌ها را به فایل‌های بهینه‌شدهٔ محلی یا CDN مجموعه منتقل کرد.

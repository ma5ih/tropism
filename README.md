# تروپیسم — وب‌سایت فارسی رزرو جلسهٔ تراپی

صفحهٔ اصلی واکنش‌گرا با **Next.js 15، React، TypeScript و Framer Motion**؛ با طراحی RTL فارسی، انیمیشن‌های ملایم، بخش خدمات، معرفی رویکرد، پرسش‌های پرتکرار و پنجرهٔ انتخاب نوع جلسه.

## اجرا در کامپیوتر

به Node.js نسخهٔ 20.9 یا جدیدتر نیاز دارید.

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

برای ساخت نسخهٔ نهایی:

```bash
npm run build
npm run start
```

## ساختار

- `app/page.tsx` — صفحهٔ اصلی و تعاملات کاربر
- `app/globals.css` — طراحی واکنش‌گرا، فاصله‌گذاری و انیمیشن‌ها
- `app/layout.tsx` — تنظیم زبان فارسی، RTL و متادیتا
- `public/logo.svg` — نشانهٔ گرافیکی تروپیسم

## نکته دربارهٔ رزرو

فرم انتخاب مسیر در این نسخه نمایشی است و اطلاعاتی ارسال یا ذخیره نمی‌کند. برای رزرو واقعی باید API و بک‌اند، مدیریت زمان‌های خالی، پایگاه داده و ارسال تأییدیه به آن متصل شود. نشانی `hello@tropism.example` نمونه است و قبل از انتشار باید با نشانی واقعی جایگزین شود.

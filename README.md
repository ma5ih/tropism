# Tropism — پلتفرم رزرو جلسات تراپی

پروژهٔ صفحهٔ اصلی وب‌سایت تروپیسم با Next.js، TypeScript و طراحی راست‌چین فارسی.

## اجرا
```bash
npm install
npm run dev
```
سپس آدرس `http://localhost:3000` را باز کنید.

## رنگ‌های برند
- Olive: `#6a804a`
- Purple: `#9b76b4`
- Light Gray: `#dbdbdb`

> فرانت‌اند صفحهٔ اصلی است. رزرو واقعی باید به بک‌اند و سامانهٔ زمان‌بندی متصل شود.
